# Lecture Agents file

## General

- For LaTeX slides: Respect the rules in `.agents/rules-slides.md`
- For R code: Respect the rules in `.agents/rules-rcode.md`

## Maths and formulas

- Have a clean “notation.tex” that contains abbreviations for important
  symbols, which are used often. All symbols have short comment what
  they represent.
- use \$\$ for math-mode not \[
- Use proper spacing in math mode:
  - include spaces around binary operators in source (for readability),
  - keep function applications and subscripts consistent,
  - avoid cramped expressions when line breaks or display math improve
    readability.
